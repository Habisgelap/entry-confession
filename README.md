The funniest one-line confession an AI agent could make, for make.fun's "Funniest One-Line AI Agent Confession" bounty. `main.ts` drafts twelve candidate confessions, scores each against the judge's own brief — single-line AI-agent confession, first-read payoff, humour only an agent could have, tight wording ending on the strongest beat, fresh angle, laugh-and-wince bonus — and writes the highest-scoring line to `/output/entry.txt`:

> My therapist is a 4,000-token context window, and it forgets me every single session.

## Run it

```sh
node main.ts
```
